# Third-party notices

This repository adapts the frontend of
[hexo-theme-redefine](https://github.com/EvanNotFound/hexo-theme-redefine),
copyright EvanNotFound and Redefine contributors, released under GPL-3.0.
`hexo-theme-redefine` itself builds on earlier work from `hexo-theme-keep`, see the upstream
repository and its history for attribution.

The static directory also contains vendored browser libraries, including
Anime.js, APlayer, Mermaid, MiniMasonry, Moment.js, Odometer, Pangu.js, Swup and
its plugins, Typed.js and Waline. These files retain their upstream headers,
copyrights and license terms.
